## 使用说明

PNG 总览用于核对商品和图片顺序。总览中的小图经过缩略排版，独立图片保留各自原有尺寸与比例；后续作图请使用完整 URL 清单中的独立图片直链。1280 张原始辅图未重新编码、未缩小、未压缩画质；已发布的 321 张白底主图沿用审核版本，其中 13 张背景处理图为无损 PNG。大图发布文件也保持生成后的 PNG 原文件字节。
