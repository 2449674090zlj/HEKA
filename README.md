# HEKA 商品白底主图

本仓库提供 321 个 SKU 的主图，覆盖 5 份上架模板中的商品。每个 SKU 对应一张主图；模板之间重复出现的 SKU 使用同一张主图。

- 308 张原本已为白底的 JPG 主图按原文件字节保留，未重新编码。
- 13 张需要处理背景的主图仅将背景改为白色，保存为无损 PNG。产品来自原图像素，保留产品造型、颜色、结构和配件，不使用生成式重绘。
- 所有图片保留原始像素尺寸，不缩小分辨率；原有 JPG 按原文件保留，处理图使用无损 PNG。

文件按 `SKU_IMAGE01.jpg` 或 `SKU_IMAGE01.png` 命名。请使用配套 URL 清单中每个 SKU 的实际文件扩展名。

图片公开直链规则：

```text
https://raw.githubusercontent.com/2449674090zlj/HEKA/main/文件名
```

配套 URL 清单的两列为 `SKU` 和 `IMAGE1`。原始来源、处理状态及文件校验信息另存于交付审计清单。

全部图片为 1:1，原始尺寸为 1000×1000 至 3008×3008 像素。5 份模板共有 378 条商品行，去重后为 321 个 SKU；两份 Indoor Games 模板包含相同的 57 个 SKU。Bike 文件名中的 187 为原文件命名，实际有效商品行为 176 行，未补造或删除商品。

原图细节限制：`W2031127626` 的篮网与树叶、`T3971P441991` 的球门细网与床单低对比重叠，处理时保留可辨认的原始网绳像素。前者部分细网仍带有原环境的青绿色反光；没有重画、去色或合成产品细节。
