## 图片质量与处理范围

- **原始辅图不重新编码、不缩小尺寸、不压缩画质。** 1280 张辅图按下载后的原始文件字节发布，保持各自原有像素尺寸和宽高比例。
- 321 张主图中，308 张原本已为白底的 JPG 按原文件字节保留；13 张需换背景的主图使用原产品像素，替换背景后保存为无损 PNG，保留原始像素尺寸，没有生成式重绘。
- 总览大图是将主辅图缩略排版后保存的 PNG，方便核对 SKU 和图片顺序。独立图片直链对应各自原文件或已审核的无损主图处理版本；请下载独立图片用于后续作图。
- 目前主图均为 1:1，原始尺寸为 1000×1000 至 3008×3008 像素。辅图保留来源尺寸与比例。

原图细节限制：`W2031127626` 的篮网与树叶、`T3971P441991` 的球门细网与床单存在低对比重叠。处理时保留可辨认的原始网绳像素，部分细网保留原环境的青绿色反光或边缘混色，没有重画、去色或合成产品细节。
